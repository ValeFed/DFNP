# Dynamic Fault Nucleation and Propagation Altorithm

The DFNP - Dynamic Fault Nucleation and Propagation Algorithm, is an algorithm for the tracking and representation of mechanical discontinuities within finite-element models buildt on quadratic-triangular elements. 

The full workflow consists in the tracking subroutines used in `TrackDiscontinuity\` combine dwith the Automatic Mesh Refinement algorithm described and tested in `QuadReg\`. The full description of the code and the tests will be available soon in Fedeli and Marotta (in prep).

# Dynamic Fault Nucleation and Propagation Algorithm

The DFNP (Dynamic Fault Nucleation and Propagation Algorithm) is an algorithm for the tracking and representation of mechanical discontinuities within finite-element models built on quadratic-triangular elements. 

The full workflow consists of the tracking subroutines used in `TrackDiscontinuity\` combined with the Automatic Mesh Refinement algorithm described and tested in `QuadReg\`. The full description of the code and the tests will be available soon in Fedeli and Marotta (in prep).
